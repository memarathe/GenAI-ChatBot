# 🧠 Tinyllama Web Interface via Gradio

This project provides a lightweight web interface for interacting with the locally hosted **Tinyllama** language model using **Gradio** and **Ollama**. It enables users to input prompts and receive AI-generated responses in real time.

- Local model hosting via Ollama  
- Interactive web UI using Gradio
